Sample files for development. No production or personal data.

Research evidence lives in `research/`, grouped by the original research rounds.
Each bundle keeps its captures, profiles, manifests, checksums, fixtures and
source-document snapshots together. Downloaded code in those snapshots is
untrusted reference material, not executable project code.

Probe and analysis scripts remain in `../docs/research/scripts/`. Existing
`docs/research/` paths recorded inside evidence are historical provenance;
resolve them under `data/research/` now, except for scripts.

Research bundles remain Git-ignored, matching their previous local-only status.
Copying evidence does not authorize collection, redistribution or cloud uploads.
